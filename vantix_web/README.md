# Vantix Web

Frontend Vue/Vite cho Vantix HRM.

## Chạy frontend

```powershell
cd D:\Learning\Vantix\vantix_web
npm install
npm run dev
```

Ứng dụng chạy tại:

```text
http://localhost:3000
```

Backend cần chạy tại:

```text
http://localhost:8080
```

Vite proxy các request `/api` về backend. Tài khoản test, cách chạy toàn bộ hệ thống và mô tả nghiệp vụ nằm trong:

```text
D:\Learning\Vantix\README.md
```
